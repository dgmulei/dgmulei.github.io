# David Mulei Website Project - Session Notes

## Project Overview
Building a new personal website hosted on GitHub Pages to replace existing Squarespace site at www.davidmulei.com.

**Repository:** dgmulei.github.io
**GitHub Account:** https://github.com/dgmulei

## Design Philosophy

### Core Positioning
David Mulei as **writer-researcher-dramaturg** - someone who works with source material (historical records, literary texts, archival research) to craft dramatic narratives. The key value proposition: "dramaturgical rigor" - the ability to compress months of research into coherent narrative architecture with prestige-TV-level historical accountability.

### Visual Direction
- **References:** Paris Review, Granta, The Atlantic, The New Yorker (literary, not film/theater pizazz)
- **Aesthetic:** Text-driven, editorial, sophisticated - signals "serious writer with taste"
- **Typography as craft:** Beautiful serifs, generous leading, proper hierarchy
- **Warm, paper-like quality:** Cream/off-white backgrounds, rich blacks

### Design Details (V2)
- **Fonts:**
  - Crimson Pro (body text - literary serif)
  - IBM Plex Mono (titles/headings - manuscript/typewriter connection)
  - Inter (navigation)
- **Colors:**
  - Background: #faf9f6 (warm cream)
  - Text: #2a2a2a to #3a3a3a (rich, not pure black)
  - Accent: #8b3a3a (deep burgundy, used sparingly)
- **Details:**
  - Hairline borders (0.5px)
  - Drop cap on homepage opening (burgundy "S")
  - Small caps for metadata
  - Centered navigation (just: Work | Bio | Contact)
  - Minimal footer (just "© 2026")

### Key Design Decisions
1. **No images** - Text-only. The writing does the work. This represents the writerly way of looking at the world.
2. **No nav logo** - Removed redundant "DAVID MULEI" from nav (you're already on davidmulei.com)
3. **Simple tagline** - Just "Writer" (not "Writer. Researcher. Dramaturg." which felt resume-y)
4. **Drop cap "S" not "I"** - Changed opening paragraph to start with "Source material..." so drop cap emphasizes the work/process, not the person
